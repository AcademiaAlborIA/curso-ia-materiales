## 🛠️ ¿Cómo usar cada archivo `.zip`?
1. Haz clic en el enlace **Descargar** correspondiente al capítulo que estás viendo.
2. En tu computadora, haz clic derecho sobre el archivo `.zip` descargado y selecciona **Extraer todo...** (Windows) o haz doble clic (Mac).
3. Abre el archivo de guía incluido dentro de la carpeta descomprimida y sigue el paso a paso junto con el video.

> **Nota educativa:** Todos los conjuntos de datos incluidos en este repositorio son sintéticos o ficticios, creados específicamente con fines didácticos para aprender sin exponer información personal ni privada.
